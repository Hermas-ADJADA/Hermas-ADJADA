## 🚀 Projet phare : Network Management System (NMS)

Plateforme complète de gestion réseau d'entreprise, développée dans le cadre de mon mémoire de Licence :

- **Architecture** : hexagonale Django, écosystème Docker de 15 services spécialisés
- **Gestion réseau** : découverte automatique d'équipements (SNMP, SSH, API), topologie dynamique temps réel, configuration multi-vendor
- **Monitoring** : Prometheus, Grafana, Netdata, ntopng, détection d'anomalies par machine learning
- **Sécurité** : SIEM Elastic Stack, IDS/IPS Suricata, protection Fail2Ban, audit trail complet
- **QoS** : algorithmes HTB, FQ-CoDel, DRR, CBWFQ, inspection profonde de paquets
- **Automation** : API REST documentée (Swagger), workflows Celery, intégration GNS3
